# Historical AnyPS5 patch series

These 75 patches belong to AnyPS5 `6e037e9899efb7439913a6e1151b901a92c9c9c8`.
Their original bytes and hashes are preserved for existing build receipts and
review. They are not applied to the new main pin.

The active top-level series was reconciled against full main `d70b8998`. It
retains required iPad/Wine compatibility while adopting the new upstream shader
and runtime architecture. Some old changes are now upstream implementations;
reapplying this old series would overwrite or conflict with those implementations.
See [full integration](../../../docs/ANYPS5-MAIN-INTEGRATION.md).
